# Building-AI

## How do we construct better predictors?

This directory contains research, implementations, and explorations of machine learning models, algorithms, and techniques that form the foundation of AI systems.

### The Evolution of AI Models

```
LINEAR MODELS (1950s)
        │
CLASSIFICATION (1970s)
        │
NEURAL NETWORKS (1980s)
        │
DECISION TREES (1984)
        │
BAGGING (1996) → RANDOM FOREST (2001)
        │
BOOSTING → XGBOOST / LIGHTGBM (1995–2016)
        │
DEEP LEARNING (CNNs / Transformers, 2012+)
        │
     [ongoing]
```

### Contents

This folder contains implementations and research on:

- **Classical Machine Learning**: Linear models, classification algorithms, decision trees
- **Ensemble Methods**: Bagging, boosting, random forests, gradient boosting
- **Deep Learning**: Neural networks, convolutional networks, transformer architectures
- **Natural Language Processing**: Language models, embeddings, fine-tuning techniques
- **Computer Vision**: Image processing, object detection, segmentation
- **Reinforcement Learning**: Policy learning, value functions, multi-agent systems
- **Advanced Topics**: Emerging architectures and experimental approaches

### Building Blocks

Each implementation explores:
- Core algorithm mechanics
- Performance characteristics
- When to use this approach
- Practical applications
- Trade-offs and limitations
