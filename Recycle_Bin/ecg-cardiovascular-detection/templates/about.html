Detection of Cardiovascular Diseases in ECG Images Using Deep Learning Methods

About This Project

This project detects cardiovascular diseases from ECG images using deep learning methods. The system uses a proposed CNN architecture to classify four major cardiac abnormalities: abnormal heartbeat, myocardial infarction, history of myocardial infarction, and normal person classes.

Technologies Used
  • Python
  • Flask
  • TensorFlow / Keras
  • NumPy
  • Pandas
  • Scikit-learn
