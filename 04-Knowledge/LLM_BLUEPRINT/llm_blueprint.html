LLM From-Scratch Blueprint — Data → Training

flowchart TD S1["0a. Set config: vocab_size, d_model,
n_layers, n_heads, seq_len, batch_size"] --> S2["0b. Set random seed
for reproducibility"] S2 --> A1 A1["1. Raw text corpora
Common Crawl, Wikipedia, books, code"] --> A2["2. Cleaning: dedup, language filter,
quality filter, PII/toxicity removal"] A2 --> A3["3. Train tokenizer BPE on cleaned corpus
build vocab, define special tokens:
BOS, EOS, PAD, UNK"] A3 --> A4["4. Encode full corpus with tokenizer
text to token ID sequences"] A4 --> A5["5. Pack into fixed-length chunks
e.g. 2048 tokens/sequence, insert BOS/EOS,
no padding waste"] A5 --> A6["5b. Shuffle sequence order
redo every epoch"] A6 --> W1["0c. Initialize model weights
small scaled random init, e.g. Gaussian x 0.02
done once, before training starts"] W1 --> B1["6. Token IDs, shape: batch x seq_len"] B1 --> B2["7. Embedding lookup table
vocab_size x d_model, e.g. 50000 x 4096
trainable matrix"] B2 --> B3["8. Token embeddings
shape: batch x seq_len x d_model"] B3 --> B4["9. Add positional encoding
RoPE rotates Q,K by angle proportional to position
OR sinusoidal / learned added directly"] B4 --> C0["10. Hidden state x
enters Transformer block, repeat N times"] subgraph BLOCK["Transformer Block (repeated N times, e.g. 32 layers)"] direction TB C0 --> C1["11. Pre-Norm: RMSNorm on x"] C1 --> C2A["12a. Linear projection W_Q: x times W_Q equals Q"] C1 --> C2B["12b. Linear projection W_K: x times W_K equals K"] C1 --> C2C["12c. Linear projection W_V: x times W_V equals V"] C2A --> C3["13. Split Q,K,V into multiple heads
e.g. 32 heads of 128 dim each, run in parallel"] C2B --> C3 C2C --> C3 C3 --> C4["14. Compute scores: Q dot K transpose"] C4 --> C5["15. Scale: divide scores by sqrt of d_k
prevents softmax gradient vanishing"] C5 --> C6["16. Apply causal mask:
set future positions to -infinity
lower-triangular allowed matrix"] C6 --> C7["17. Softmax over scores
turns into attention probability weights"] C7 --> C8["18. Multiply weights by V
weighted sum = contextual token repr"] C8 --> C9["19. Concatenate all heads back together"] C9 --> C10["20. Output projection W_O"] C10 --> C10D["20b. Dropout on attention output
randomly zero values, training only
off during inference"] C10D --> C11["21. Residual add: x = x + attention_output"] C11 --> C12["22. Pre-Norm: RMSNorm on x"] C12 --> C13["23. FFN Linear1: expand d_model to 4x d_model
e.g. 4096 to 16384"] C13 --> C14["24. Nonlinearity: SwiGLU / GELU activation"] C14 --> C15["25. FFN Linear2: project back down
16384 to 4096"] C15 --> C15D["25b. Dropout on FFN output
training only"] C15D --> C16["26. Residual add: x = x + ffn_output"] end C16 --> D0{"27. More layers left?"} D0 -- yes, loop back --> C0 D0 -- no, done --> E1["28. Final RMSNorm / LayerNorm"] E1 --> E2["29. Output projection LM head
d_model x vocab_size, often weight-tied to embedding table"] E2 --> E3["30. Logits: batch x seq_len x vocab_size
raw score per possible next token"] E3 --> E4["31. Softmax over vocab dimension
probability distribution for next token"] E4 --> F0{"32. Training or Inference?"} F0 -- Training --> F1["33. Cross-entropy loss:
compare predicted dist vs actual next token
target = input shifted by 1 position"] F0 -- Inference --> F2["33b. Sample next token:
greedy / top-k / top-p / temperature"] F1 --> G1["34. Backward pass: loss.backward
autograd computes gradient for every weight"] G1 --> GA{"34b. Accumulated enough
micro-batches? e.g. every 4"} GA -- no, next micro-batch --> B1 GA -- yes --> G2["35. Gradient clipping:
clip_grad_norm to e.g. max_norm 1.0
caps update size, prevents explosion"] G2 --> G3["36. Optimizer step: AdamW
uses momentum + adaptive per-param scaling
+ weight decay regularization"] G3 --> G4["37. Learning rate scheduler step:
Warmup phase, LR ramps 0 to target
then Cosine decay, LR smoothly to ~0"] G4 --> G5["38. optimizer.zero_grad
clear gradients for next step"] G5 --> G6{"39. Step % save_every == 0?"} G6 -- yes --> G7["40. Checkpoint: save model weights
+ optimizer state + step number to disk"] G6 -- no --> G8["41. Log loss and perplexity
perplexity = e ^ loss"] G7 --> G8 G8 --> GV{"41b. Step % eval_every == 0?"} GV -- yes --> GV2["41c. Run validation pass:
held-out data, no dropout,
no backward pass, log val loss"] GV -- no --> G9 GV2 --> G9{"42. More batches left in this epoch?"} G9 -- yes, next batch --> B1 G9 -- no --> G10{"42b. More epochs left?"} G10 -- yes, next epoch --> A6 G10 -- no, training done --> H1["43. Trained model checkpoint
ready for eval or inference"] F2 --> H2["44. Generated token appended to sequence
fed back in for next-token prediction"] H2 --> B1
